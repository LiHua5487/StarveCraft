# StarveCraft

当史蒂夫来到永恒大陆——用 MC 的视角和操作探索饥荒世界！

两款游戏同时在本机运行：Minecraft 负责玩家、背包、装备和方块，饥荒负责生物、资源、物品变化和世界时间；饥荒的原版纸片美术会直接显示在 MC 中，不依赖透明窗口叠加

## 主要内容

- 采摘、砍树、挖矿、战斗和放置建筑
- 饥荒生物、地面掉落物、昼夜、天气与火把照明
- 饥荒物品保留自身材质和功能, 食物会继续腐烂, 容器继续运行原版逻辑
- 使用 MC 合成栏和配方书制作饥荒物品, 配方分类及科技要求跟随饥荒
- 配方书提供单独的物品转换类别, 用于兑换 MC 与饥荒的对应物品
- 按 M 打开饥荒原版地图, 按键可在 MC 设置中修改

## 运行要求

- Windows
- Minecraft 26.3
- Fabric Loader 0.19.5
- Fabric API 0.162.0+26.3
- Java 25
- Steam 版饥荒（巨人国 DLC）

> 本模组对应单机版 Don't Starve，不是 Don't Starve Together / 饥荒联机版

## 安装

从本仓库 Releases 下载同一版本的两端模组
- Minecraft 端：安装 Fabric 与 Fabric API，并将 `starvecraft-0.3.8.jar` 放进实际游玩版本的 `mods` 文件夹
- 饥荒端：下载并解压 `starvecraft-ds-0.3.8.zip`, 将里面的整个 `starvecraft` 文件夹放进饥荒安装目录下的 `mods` 文件夹

## 开始游玩

- 启动 MC 并进入单人游戏, 新建世界，将世界类型切换到 "永恒大陆"
- 进入世界后, 模组会自动启动饥荒，并创建或加载对应的配对存档
- 等待连接完成后即可游玩, 饥荒就绪后会自动最小化

## 基本操作

- 左键攻击生物, 使用对应工具砍树、挖矿
- 右键采摘植物、拾取饥荒地面掉落物、打开容器、放置建筑
- Shift + 右键绕过目标交互, 继续使用手持物品
- 使用 MC 的配方书合成饥荒物品
- 连接中断后点击“重新配对”，模组不会反复自动重启饥荒

## 存档说明

MC 与饥荒分别保存各自负责的内容，两边存档通过配对信息关联，再次进入 MC 存档时会加载对应的饥荒世界

正常退出使用 MC 的保存退出

删除 MC 中的配对存档也会删除对应的饥荒世界，如果饥荒当时没有运行, 会在下次后台启动后完成清理，备份时请同时保留两边存档
